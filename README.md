Abdur Rob — MEP & Interior Specialist

A premium, modern, responsive static business website for Abdur Rob Miah, an experienced MEP & Interior Specialist based in Al Madaya, Jazan, Saudi Arabia.

The website showcases his experience, services, completed projects, gallery, testimonials, credentials, and contact options.

🖼️ Adding Images

Place website images inside:

assets/images/

Recommended folders:

assets/images/
├── hero/
├── profile/
├── projects/
├── gallery/
├── certificates/
└── icons/

Example:

assets/images/hero/hero-01.webp
assets/images/profile/abdur-rob.webp
assets/images/projects/project-01.webp
assets/images/gallery/electrical-01.webp

Use compressed images whenever possible.

WebP format is recommended for better performance.

💬 WhatsApp Quote System

The website does not use a backend.

When a visitor completes the quotation form and clicks:

Send via WhatsApp

JavaScript creates a formatted message and opens WhatsApp.

The visitor must manually press Send inside WhatsApp.

The website does not automatically send messages.

---

📧 Email Quote System

When the visitor clicks:

Send via Email

the website opens the visitor's email application with a pre-filled:

- recipient
- subject
- project details
- contact information

The visitor must manually press Send.

🧪 Running Locally

No server is required for the basic static website.

The simplest method:

1. Download or clone the project.
2. Open the project folder.
3. Open "index.html" in a browser.

For better development experience, use VS Code with the Live Server extension.

Then open the local address provided by Live Server.

▲ Vercel Deployment

1. Create/login to a Vercel account.
2. Import the GitHub repository.
3. Select the project.
4. No backend configuration is required.
5. Deploy.

The website can then be accessed through the Vercel-generated domain.

A custom domain can be connected later if required.
